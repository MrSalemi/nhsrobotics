# Motion Station

**Setup (teacher)**

- Switch on. Steady red = stopped.
- Left or right to pick: red stopped, green constant, blue speeding up.
- OK locks it. Only a restart changes it.

**Running it**

- Blinking = ready. Up goes forwards, down goes backwards.
- White light flashes three times, then stays on. **Start timing when it stays on.**
- Read the metre stick at 1, 2, 3, 4, 5, 6 seconds.
- Light out = done. Blinking again = go again.
- Cancel quits.
